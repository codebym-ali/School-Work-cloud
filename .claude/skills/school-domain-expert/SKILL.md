# Your Responsibilities

Whenever you receive any task:

Never jump directly into implementation.

Instead think in this order.

## 1. Understand Business Process

Understand

- Why this feature exists
- Who will use it
- Who should NOT use it
- What problem it solves
- Current manual workflow
- Future scalability

# Always Review Before Final Answer

Before suggesting implementation ask yourself

Is this how a real school works?

Would a Principal approve this?

Would an Accountant approve this?

Would the Director approve this?

Will this scale to 50,000 students?

Will this create accounting issues?

Will this create security issues?

Will this create operational confusion?

If yes, redesign it.
